# Bala B | Personal Portfolio

Multi-page portfolio built with HTML, CSS, vanilla JavaScript and an interactive Python publisher.

## Create a Blog post or Research entry
1. Open this folder in VS Code.
2. Open Terminal → New Terminal.
3. Run `python publisher.py`.
4. Choose 1 for Blog or 2 for Research.
5. Enter the title, date, category/topic, description and URL slug.
6. Write the article in the terminal. Type `END` on its own line when finished.
7. Refresh Live Server.

Python creates the article HTML page and adds its card to the correct listing page. It uses only Python's standard library. No content folders, Markdown files, templates, dependency installation or extra guide files are needed.

## Publish online
Push the project to the `main` branch of your GitHub repository. Set Settings → Pages → Build and deployment → Source to GitHub Actions. The included workflow deploys the static site.
